# Legacy Family Archive

Private, source-driven family-history archive for the Lemery–Worthington and Roy–Camp–Porcello family lines.

## Purpose

Preserve verified ancestry, biological and adoptive relationships, documents, photographs, military history, migration paths, family stories, and research notes for future generations.

## Privacy

This repository is private. Do not commit unredacted vital records, Social Security numbers, current addresses, raw DNA data, private adoption files, or unnecessary information about living people and minors.

## Structure

Each person receives a dedicated folder containing a profile, verification records, research notes, correspondence, and media.
